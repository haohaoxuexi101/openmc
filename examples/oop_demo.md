# GeometryState / ParticleData / Particle 面向对象示例

该示例依据 OpenMC 中的类继承关系，抽象出一个可以直接编译运行的
C++ 程序，用于教学演示。

## 类之间的关系

```
GeometryState  <- 管理几何坐标、方向和历史轨迹
    |
    v
ParticleData   <- 在几何状态的基础上，增加能量、权重、碰撞计数等粒子属性
    |
    v
Particle       <- 提供“运动”“碰撞”“打印结果”等行为，利用前两个类维护的状态
```

这种分层设计与 OpenMC 源码中的 `GeometryState`、`ParticleData`、`Particle`
类一致：底层负责几何信息，中层保存粒子属性，顶层实现物理过程。

## 如何运行

```bash
g++ -std=c++17 examples/oop_demo.cpp -o oop_demo
./oop_demo
```

程序会依次演示：

1. 初始化粒子位置、方向、能量和权重；
2. 沿当前方向移动 10 cm；
3. 发生一次能量损失 25% 的碰撞；
4. 调整方向后再移动 5 cm；
5. 再次碰撞并损失 10% 能量；
6. 输出完整的粒子状态和轨迹历史，用于讲解继承链条中每个类的职责。

## 教学提示

- 可先展示 `GeometryState` 的代码，让学习者理解最基础的空间状态管理；
- 继而引入 `ParticleData`，讨论为何要在几何信息之上扩展粒子属性；
- 最后查看 `Particle`，说明如何通过继承复用已有状态并添加高层行为；
- 运行程序后结合输出讲解“状态 + 行为”的面向对象思想。
