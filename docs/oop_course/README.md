# OpenMC 面向对象课程

本课程以 OpenMC Python 前端的设计逻辑为模板，拆解其优秀的面向对象实践，并通过独立的教学示例帮助你掌握对应的 Python 技法。每个章节都包含简明的讲解和可运行的代码，覆盖唯一 ID 管理、可复用 Mixin、抽象基类、元类约束、属性封装、类型安全容器以及对象序列化等核心主题。
