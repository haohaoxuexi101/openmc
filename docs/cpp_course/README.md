# OpenMC 风格 C++ 课程代码

这套 20 节微课程均为 **可独立编译运行的 C++17 程序**，每节聚焦 OpenMC 的一个核心设计点：面向对象抽象、策略模式、缓存、并行友好容器、空间加速结构等。程序都带有详尽中文注释，解释设计背后的优势。

## 编译与运行

以 Lesson 01 为例：

```bash
g++ -std=c++17 lesson01_surface_interface.cpp -o lesson01
./lesson01
```

其余课程仅需替换文件名即可。建议在同一目录下按需编译，保持可执行文件整洁。

## 课程目录

| Lesson | 主题 | 亮点 |
| ------ | ---- | ---- |
| 01 | Surface 抽象接口 | 纯虚函数定义 evaluate/distance/normal，演示 HDF5 写出。 |
| 02 | 曲面构造与射线测试 | 展示不同曲面组合与命名管理。 |
| 03 | 边界条件策略模式 | 将边界行为封装为策略对象，展示可插拔设计。 |
| 04 | 简单工厂生成曲面 | 依据配置字符串创建对象，突出解耦。 |
| 05 | 粒子数据布局 | 数据类 + 行为类分离，模拟缓存字段。 |
| 06 | 事件驱动推进 | 逐事件函数避免巨型循环，演示流程日志。 |
| 07 | 截面缓存 | 根据材料与能量缓存结果，减少重复计算。 |
| 08 | 线程安全共享数组 | 原子 push_back，RAII 管理内存。 |
| 09 | span 视图 | 提供零拷贝窗口，保持 STL 风格迭代。 |
| 10 | 次级粒子银行 | 封装 split/roulette 逻辑，打印统计。 |
| 11 | 区域布尔组合 | Intersection/Union 组合 Region，示例燃料-包壳判断。 |
| 12 | Universe Cell 查询 | 职责分离的 Cell/Universe 查找点所属区域。 |
| 13 | 多态材料模型 | 策略 + 缓存包装，模拟能量依赖截面。 |
| 14 | Alias 采样算法 | O(1) 概率采样，输出分布误差对比。 |
| 15 | Track-length 计数器 | 策略式 Tallier，累积单元通量。 |
| 16 | 粒子库压缩 | 使用优先队列保留高重要性粒子。 |
| 17 | 随机数子流 | 子流衍生避免竞争，展示独立抽样。 |
| 18 | 空间加速网格 | 预处理包围盒映射，缩减候选 Cell。 |
| 19 | 几何层级描述 | CSG 区域 + Universe 描述并输出采样。 |
| 20 | 性能计时器 | ScopedTimer 自动累计阶段耗时。 |

每个程序的输出都说明所展示模式的意义，便于将理念迁移到真实的 OpenMC 代码阅读中。
